## 数据存在哪儿

全部只存在**你自己的手机或电脑**里（浏览器本地存储），不上传服务器。
换手机时用「个人设置 → 数据备份与恢复 → 导出备份」，把文件发到新手机再导入即可。

## 手机上怎么装成一个 App

iPhone：Safari 打开上面的地址 → 分享 → 添加到主屏幕。
安卓：Chrome 打开 → 右上角菜单 → 添加到主屏幕。
